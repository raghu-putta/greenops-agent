Agent Pipeline

4 specialized AI agents work in sequence — each passing context to the next

🔍
Agent 1
Carbon Scout
Scans GCP for idle VMs, unattached disks, unused reserved IPs, and rightsizing recommendations.
📊
Agent 2
GreenOps Analyzer
Calculates CO₂ impact, cost waste, and classifies each action as LOW / MEDIUM / HIGH risk.
⚡
Agent 3
Optimization Executor
Presents LOW risk actions for human approval. Executes only after explicit confirmation.
📋
Agent 4
Report Generator
Compiles a full GreenOps markdown report with cost savings, CO₂ impact, and next steps.
